# Security policy

This experimental skill supplies instructions and an optional local verification
helper. It is not a sandbox or an authorization mechanism. Configured commands run
with the caller's privileges; review the execution boundaries before adoption.

Fixes target the current default branch. No response-time SLA is promised.

Report suspected vulnerabilities using this repository's private vulnerability
reporting form under Security, if available. Otherwise contact Andreas through a
non-public contact method on the linked GitHub profile before sharing sensitive
details. Include the revision, impact, and safe reproduction steps. Never put
credentials or confidential data in a public issue.
